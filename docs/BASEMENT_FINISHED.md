# Kjellerinnredning

37 plasserte Poly Haven-modeller fordelt i seks rom, samt egen scene med knekte taklekter og skjeve dørkarmer. Store møbler har kollisjon; småskrot er dekor. Ingen generering under spilling.

Åpne scenes/horror/basement_dressing.tscn eller de enkelte basement_* romscenene for å flytte delene. Hovedscenen er house_layout.tscn. Belysning og lommelykt er uendret.

## Kontroll
BASEMENT_TEST PASS failures=0: fall, låste jernstenger, rømningshull, trapp, krypetunneler og stige.
Visuelt kontrollert celle, lager, fyrrom og verksted med arbeidslys. Beholder eksisterende mørk modus og myk lommelykt.

# Assets og lisenser

Original bilmodell, props, banelayout, vegetasjon, dekkrøyktekstur og lyder er
laget for dette prosjektet. Blender-kilden ligger i assets/source/.

Poly Haven-filer er CC0 1.0 Universal og kan brukes og distribueres i spillet:

- Asphalt 02, Rob Tuytel: https://polyhaven.com/a/asphalt_02
  1K diffuse, OpenGL normal og roughness i assets/textures/asphalt_*.jpg.
- Industrial Sunset (Pure Sky), Jarod Guest / Sergej Majboroda:
  https://polyhaven.com/a/industrial_sunset_puresky
  2K HDR i assets/textures/industrial_sunset.hdr.

Lisens: https://polyhaven.com/license
Godot Engine er MIT-lisensiert: https://godotengine.org/license/
